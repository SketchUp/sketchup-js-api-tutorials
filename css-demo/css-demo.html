This is an example of sketchup-extension.css, a tiny css file that makes your extensions look like they belong inside of SketchUp.

  • Short CSS file, easy to read and adjust.
  • Powered via normal HTML tags.

Open this page in a new tab to inspect how it works, or scroll down to see it in action.
